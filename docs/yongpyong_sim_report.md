## 진단
- **판별 로직(도미네이션)은 설계대로 동작 중.** 문제는 **폴리곤 드로잉이 과하게 겹쳐 있다는 것.** 겹친 슬로프를 타면 "가장 길고 커버리지 큰 옆 슬로프"로 기록이 흡수됨 → 유저가 "내 기록이 딴 슬로프로 됐다"고 느낄 지점.
- 특히 **레인보우1~4** 와 **레드/핑크/뉴레드** 는 서로 상단부터 크게 겹쳐 있어 진입 판별이 갈리지 않음.

## 권장 조치 (우선순위)
1. **겹침이 큰 폴리곤 재드로잉** — 레인보우1~4, 레드/핑크/뉴레드를 각자의 실제 슬로프 폭에 맞게 좁혀, 특히 **상단(진입) 구간이 서로 구분되게** 그린다. (한 폴리곤이 다른 슬로프의 axis 경로를 통째로 덮지 않도록)
2. **axis 삐져나온 6건**(#57,#52,#60,#158,#62,#123) 폴리곤을 axis 포함하도록 수정.
3. 레드파라다이스(#51)는 폭 대비 axis가 짧거나 형상이 옆으로 퍼져 있는지 확인 — 횡단 오검출 방지.
4. (선택) 재드로잉 후에도 겹침이 불가피한 하단 합류부는 domination이 "더 긴 슬로프"로 몰아주는 현재 동작을 유지할지, axis 평행도까지 보는 로직으로 보완할지 결정.

> 재드로잉 후 `sim_slopes`를 다시 돌리면 PASS 수치로 개선을 바로 확인할 수 있습니다.
