## 1. 서버 작업 필요 (2건)

### 1-1. 크루별 크루톡 조회 API

크루톡은 라이브톡과 같은 테이블에 저장되는데, **크루 단위로 읽어올 방법이 없습니다.**

실측 결과 (2026-10-06):

```
POST /api/livetalk/list/   {"crew_id": 334}   →  30건
POST /api/livetalk/list/   {}                 →  30건   ← 결과가 같음
```

돌아온 30건의 `crew_id`가 전부 `null` 입니다. 서버가 `crew_id` 파라미터를 **받기만 하고 무시**한 채
전체 라이브톡을 돌려줍니다. 크루 전용 경로는 404입니다.

반대로 **쓰기는 정상입니다.** 업로드 시 `crew_id`와 `secret`을 함께 보내고 서버가 저장하며,
응답 필드에도 `crew_id` · `secret`이 이미 있습니다. **데이터는 쌓이는데 읽는 길만 없는 상태**입니다.

**요청 사항**

| | 내용 |
|---|---|
| ① 필터 | `livetalk/list/`가 `crew_id`를 받으면 그 크루 글만 반환 |
| ② 노출 규칙 | `secret=true` 글은 **요청자가 그 크루원일 때만** 반환 |

②는 화면 구성이 아니라 정보 노출에 관한 것입니다.
크루톡 올리기의 `전체공개` 스위치를 끄면 `secret=true`로 저장되는데, 지금은 누가 볼 수 있는지
서버 규칙이 없어서 비공개 글이 전체 목록에 섞여 나올 수 있습니다.

**현재 웹 상태** — 크루홈 · 크루톡 목록은 항상 `아직 크루톡이 없어요`로 나옵니다.
UI 작업용 더미는 2026-10-05에 전부 제거했습니다.

## 7. 테스트 (2026-10-15 기준)

### 7-0. `dart:html` 때문에 웹 테스트가 **컴파일조차 안 된다** — 가장 먼저 처리 ⚠️

`maeng_4.4.5`(2026-10-15)가 홈 섹션에 `dart:html`을 들여왔습니다.

```dart
// lib/web/view/home/w_home_sections_web.dart:2
import 'dart:html' as html;
...
if (thumb != null && thumb.isNotEmpty) html.ImageElement().src = thumb;  // :1315
```

`dart:html`은 **브라우저에만** 있는 라이브러리입니다. `flutter test`는 Dart VM에서 도므로
없고, `routes_web.dart`가 거의 모든 웹 화면을 import하면서 홈 섹션까지 이어지기 때문에
**웹 위젯을 건드리는 테스트는 전부 컴파일 단계에서 막힙니다**.

- 통과 수가 **299 → 50**으로 떨어졌습니다(테스트가 틀려서가 아니라 열리지 않아서).
- **실제 웹 빌드·실행은 정상입니다** — 브라우저에는 `dart:html`이 있습니다.
- 다만 `dart:html`은 **wasm 빌드를 막습니다**(`flutter build web` 경고에 이미 떠 있음).

고치는 방법 — 썸네일 미리 받기를 `dart:html` 없이 하면 됩니다:
`precacheImage(NetworkImage(thumb), context)`(Flutter 기본, 테스트에서도 컴파일됨) 또는
`package:web`. 동작은 동일합니다.

→ 이걸 고치기 전에는 **레이아웃을 테스트로 실측해 검증할 수 없습니다**(이번 UI 작업에서
계속 쓰던 방식). 화면을 눈으로만 확인해야 합니다.

### 8-4. 다시 밟기 쉬운 함정 (이번에 실제로 밟은 것들)

- **`Obx` 안에서 observable을 하나도 안 읽으면 throw.** 더미/분기 코드를 넣을 때는
  `final real = _rx.value;`처럼 **먼저 읽고** 분기할 것.
- **웹 기본 `visualDensity`가 버튼을 깎는다**(48 → 40). `SizedBox(height:)` + `minimumSize` +

- **SVG 마스크의 rect는 흰색이어야 보인다.** `fill="white"`를 일괄 치환하면 마스크까지 검정이
  돼 내용이 통째로 사라진다(라이브크루 아이콘에서 겪음).
