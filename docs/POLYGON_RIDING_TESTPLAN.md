# 스노우라이브 — 폴리곤 라이딩 판별 모의 테스트 체크리스트

작성일: 2026-07-23
목적: 동네 평지에서 폴리곤을 그려 라이딩 판별 상태머신의 **모든 분기**를 검증
관련: [POLYGON_RIDING_PLAN.md](POLYGON_RIDING_PLAN.md)

---

## ⭐ 왜 평지에서 되나

판별은 **고도가 아니라 "축(axis) 진행률"** (수평 위치를 축에 투영)로 함. 따라서 **평지에서 완벽히 테스트 가능**.

- 폴리곤 + **축**을 그림. 축 **첫 점 = 위(top)**, 끝 점 = 아래(bottom)
- **"내려간다" = top쪽 → bottom쪽으로 걷기**
- **"역행/올라간다" = bottom쪽 → top쪽으로 걷기**
- ⚠️ 점수(`vertical_drop`)는 고도 기반이라 평지선 0에 가깝게 나옴 → **세션 판별 테스트엔 무관**

## 테스트 준비
1. 어드민(`/slope-admin/`)에서 동네에 **폴리곤 + 축** 그림 (겹침 케이스는 폴리곤 2개)
2. 각 테스트마다 걸으면서 **세션 시작/커밋 여부·카운트·slope_id**를 로그/디버그로 확인
3. 임계값(진입 2점 / 밴드Δ / 이탈 2~3점 / 재진입 유예)은 이 테스트로 실측 튜닝

---

## A. 세션 시작(진입)

- [ ] **A1** 폴리곤 밖 → 안으로, 아래방향(top→bottom) 진입 → **✅ 세션 시작**
- [ ] **A2** 폴리곤 안에서 위방향(bottom→top) 이동 (리프트 흉내) → **❌ 시작 안 함**
- [ ] **A3** 폴리곤 안에서 정지 후 아래로 출발 (리프트 내려 라이딩) → **✅ 세션 시작**
- [ ] **A4** 폴리곤 옆면으로 진입해 가로(횡)로만 이동 (진행률 증가 없음) → **❌ 시작 안 함**
- [ ] **A5** 폴리곤 경계를 살짝 스치고 바로 나감 → **❌ 시작 안 함**(2점 확정 실패)

## B. 진행 중

- [ ] **B1** 계속 아래로 종주 → **✅ 세션 유지**, 진행률 증가
- [ ] **B2** 중간에 가로질러(횡단) 걷기 (진행률 정체) → **✅ 세션 유지** (정체는 종료 아님)
- [ ] **B3** S자로 크게 돌며 잠깐 위로 역행 (밴드 Δ 이내) → **✅ 세션 유지**, 역행 궤적도 포함
- [ ] **B4** 중간에 멈춰 섬 → **✅ 세션 유지**

## C. 세션 종료(커밋)

- [ ] **C1** 아래 끝으로 폴리곤 이탈 → **✅ 커밋** (연속 2~3점 밖 확정 후)
- [ ] **C2** 중간에서 위로 크게 역행 (리프트 재탑승, 밴드 Δ 초과) → **✅ 종료·커밋**, 종료점=최하단, 이후 재하강 시 새 세션
- [ ] **C3** 걸어서 위로 올라가며 폴리곤 밖으로 → **✅ max−Δ 후퇴로 종료**, 하강분만 커밋

## D. 경계 노이즈 / 재진입

- [ ] **D1** 경계에서 한 발 밖→안 (GPS 튐 흉내) → **✅ 세션 유지** (이탈 히스테리시스)
- [ ] **D2** 폴리곤 밖으로 나갔다 곧바로 재진입 → **✅ 기존 세션 이어감** (쪼개짐/중복 없음)
- [ ] **D3** 완전히 나갔다 한참 뒤 위에서 다시 진입 → **✅ 새 세션** (2회차 카운트)
- [ ] **D4** 경계선을 톱니처럼 들락날락 → **✅ 세션 유지**, 오종료 없음

## E. 겹침 (폴리곤 2개)

- [ ] **E1** 하단 공유: A 상단 시작 → 공유하단 → 끝 → **✅ A 1회**, B 억제(dedup)
- [ ] **E2** 하단 공유: B 상단 시작 → 공유하단 → 끝 → **✅ B 1회**, A 억제
- [ ] **E3** 하단 공유인데 A 폴리곤이 짧아 먼저 이탈 → **✅ 커버리지 큰 쪽 귀속** (먼저 끝나도 지배 판정)
- [ ] **E4** 중간 합류: A 타다 B 중간으로 넘어가 B 끝까지 → **✅ A 1 + B 1** (A는 벗어나 커밋, B도 커밋)
- [ ] **E5** 완전 별개 두 폴리곤 연속 A→B → **✅ A 1 + B 1**

## F. 리프트/비라이딩 오판 방지

- [ ] **F1** 폴리곤 위를 가로질러 지나감 (축 진행 없음) → **❌ 카운트 0**
- [ ] **F2** 폴리곤을 축 따라 위로 통과 (리프트 상향) → **❌ 카운트 0**

## G. 친구위치(User_live_position) — 서버 값 확인

- [ ] **G1** 세션 시작 순간 → `is_riding=true`, `slope_id=그 슬로프` (즉시)
- [ ] **G2** 커밋 순간 → `is_riding=false`, `slope_id=null`
- [ ] **G3** 연속 A→B → `slope_id` A→B로 전환

2. **경계 노이즈에 안 쪼개짐** — D1, D2, D4
3. **겹침 귀속 정확** — E1, E2, E3
