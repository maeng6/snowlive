## 3. 검증 메커니즘 & 테스트 케이스 (전체)

### ① 정적 기하 검사 (폴리곤 자체)
| 검사 | 방법 | 정상 / 조치 |
|---|---|---|
| axis-폴리곤 정합 | axis 내부 7점(5~95%)이 폴리곤 안인지(2m 허용, 끝점 제외) | 밖이면 → **폴리곤을 axis 포함하게 재드로잉** |
| 폴리곤 면적 겹침 | 쌍별 GEOS `intersection().area`, 작은쪽 대비 % | **작은쪽 대비 40%+ → 재드로잉 1순위** |
| 하단 공유(합류) | A·B 하단점 30m 이내 | 정상 가능(공유하단). 겹침 큰 것과 겹치면 주의 |

### ② 합성 라이딩 시뮬 (슬로프별 4종)
각 슬로프마다 가짜 GPS 궤적을 만들어 판별기에 투입:
| 케이스 | 궤적 생성 방법 | 기대 결과 | FAIL 플래그 |
|---|---|---|---|
| **정상 하강** | axis 상단→하단 5m 간격 | 자기 슬로프만 1커밋 | `미검출` / `교차오검출→[X]` |
| **부분 라이딩** | axis 상단 25%만 하강 | 커버리지(m) 참고값 | (플래그 없음, 값만) |
| **리프트 횡단** | 중간점 수직 방향 폭 횡단 | 커밋 없어야 함 | `리프트횡단오검출` |
| **역행(리프트 상향)** | axis 하단→상단(진행률 감소) | 커밋 없어야 함 | `역행오검출` |

### ③ 연속/합류 라이딩 (슬로프 이어짐)
> **검출 방법(중요)**: A 하단점과 **B '축'의 최단거리**(끝점 아님!)가 **50m** 이내면 이어짐 후보.
> 붙는 지점의 **B 진행률(mpr)** 로 종류 구분. 단 **mpr≥0.9 이거나, B의 합류후 구간(mpr~1.0)이 A 폴리곤에 80%+ 잠기면 = 공유하단으로 보고 연속에서 제외**(②로 검증). (끝점만 비교하면 중간합류·비스듬한 상단연결을 놓치고, 잠김검사 없으면 공유하단을 연속으로 오분류함)

| 토폴로지 | 정의(mpr = 붙는 B 진행률) | 궤적 | 기대 결과 |
|---|---|---|---|
| **상단연결** | mpr < 0.1 (B 상단 근처) | A 완주 + B 상단부터 하강 | **A·B 둘 다 커밋** |
| **중간합류** | 0.1 ≤ mpr < 0.9 (B 중간에 합류) | A 완주 + B를 mpr 지점부터 하강 | **A·B 둘 다 커밋**(B는 mpr~1.0 부분) |
| **공유하단** | mpr ≥ 0.9 (B 하단서 합쳐짐) | A 단독 하강 | **A만 커밋**(B는 도미네이션 억제) — ②의 `교차오검출` 없음으로 검증 |

> ⚠️ 리조트마다 토폴로지가 다르다. 상단연결·중간합류가 없고 전부 공유하단이면 ③은 "연결 없음"으로 나오는 게 정상 — 그 경우 ②로 충분.

## 4. 체크리스트 (리조트별 판정)
- [ ] 모든 슬로프 **area+axis 둘 다** 있는가
- [ ] **axis-폴리곤 정합** 경고 0건인가
- [ ] **겹침 쌍** 중 작은쪽 대비 40%+ 있는가 → 재드로잉 후보
- [ ] **정상하강 전부 PASS**인가 (요약의 `N/N PASS`)
- [ ] **교차오검출 / 역행오검출** 0건인가
- [ ] **연속/합류** PASS인가 (연결 있으면 A·B 둘 다 / 연결 없으면 공유하단으로 대체 검증)
- [ ] **리프트횡단 오검출** 있으면 → 실제 그 슬로프를 가로지르는 리프트/캣트랙이 있는지 확인 (없으면 비해당)

## 5. 판정 로직 핵심 (참고)
- **진입**: 폴리곤 안 + 진행률 하단방향 증가(연속 2점)
- **종료**: max 진행률에서 밴드(25m) 후퇴 또는 폴리곤 이탈(연속 2점 밖)
- **커버리지 = 실제 지나간 축 구간(5m bin) 비율** (스팬 max-entry 아님 → 투영 착시 방지)
- **dedup(지배) = 시간포함(nesting) 기반**: 후보 B의 세션이 다른 후보 A의 세션 안에 **완전히 들어가면(늦게 시작+먼저/같이 끝남) B를 억제**(= B는 A에 올라탄 승객). 실질 겹침(≥50%)일 때만 보조로 진행률 비교. → **부분주행(중간합류)도 실제 탄 슬로프가 감싸므로 올바르게 귀속**, 연속(A→B, 서로 안 감쌈)은 둘 다 커밋.
- **드로잉 가이드**: 겹침은 균일할 필요 없음. 단 **각 슬로프는 자기만의 고유 상단(진입부)** 을 가져야 함. 한 폴리곤이 다른 폴리곤을 통째로 삼키면(near-duplicate, 겹침 100%) 구분 불가 → 그렇게 그리지 말 것.
- 각 점은 **그 폴리곤 안에 있을 때만** 해당 슬로프 진행률에 합산(단독 구간은 안 오르고 공유 구간은 둘 다 오름).
